这一页存在的理由很简单：一个不肯交代内容来源的历史产品，比没用更糟。引用任何东西之前，先读它。

## 一、内容来源——如实版本

**本仓库这 261 万字的内容库，是 AI 辅助写作。**

这句话是本页最重要的一句，所以以下精确说明它意味着什么、不意味着什么。

### 它意味着

- 文字由大语言模型生成，依据的是既有主流史学共识，再由项目作者组织进带类型的 schema。
- 选材、侧重、框架、措辞，以及"哪些节点值得写长文"的判断，都是**机器生成的决策**，只经过部分人工复核。
- 已有的英文译文同样是机器生成的，复核状态相同。

### 它不意味着

- 它**不是**任何单一参考书的转录、节选、翻译或改写。没有哪本书被数字化进这个仓库。
- 它**不是**对维基百科或任何其他百科的抓取。
- 它**不是**经过同行评议的学术成果。
- 它**不是**任何事情的一手史料。

### 你必须接受的后果

> **不要把这个内容库当权威引用。** 论文里不行，作业里不行，新闻里不行，课堂考评里不行，法律文书里不行。

史实陈述遵循主流共识，绝大多数节点在大方向上是对的。但"大方向对"不等于"已核实"，而一个 763 节点、这个篇幅的内容库必然包含错误——年代的、归属的、侧重的、遗漏的。有些错误肯定还在。**没有人把这 261 万字逐条对着史料读过。**

**找出并报告这些错误，是你能给这个项目做的最有价值的贡献。** 见[开源贡献指南](CONTRIBUTING.zh-CN.md)。

## 二、内容依据的是什么

模型的历史知识来自其训练数据中体现的通行史学共识——也就是世界史的标准学术与通俗综述。实际表现出来，就是内容与下面这类框架一致：

- 本科教学使用的通史类世界史综述；
- 标准分期（史前 / 古代 / 古典 / 中世纪 / 近代早期 / 工业 / 现代）；
- 史前与上古节点采用主流考古学与测年学结论；
- 中国史采用通行朝代纪年；
- 事件、人物、文物采用被广泛接受的年代与归属。

**这是在描述"一致性"，不是在开参考书目。** 上面任何一类中的任何具体著作，都没有在撰写任何具体节点时被查阅、复制或据以核对。声称查阅过，恰恰就是本页要避免的那种不诚实。

### 已知的系统性偏差，请留意

| 偏差 | 表现在哪 | 怎么办 |
|---|---|---|
| **年代不确定性被抹平** | 史前与青铜时代早期，学界给的是区间，这里写成单一年份 | 公元前 1000 年以前的年份一律当近似值 |
| **欧洲中心的分期** | "中世纪"被全球套用，而它本是欧洲分期 | 时代色带是导航便利，不是对世界分期的主张 |
| **共识滞后** | 较新的考古学修订可能未反映 | 有争议的一律自行核实 |
| **在争议问题上语气笃定** | 学界分歧处，行文未必会给出应有的保留 | 有争议的归属请交叉核对 |
| **深度不均** | 中国 270 个节点 vs 大洋洲 15 个 | 深度反映的是资料可得性，不是历史重要性 |

## 三、确实是人为做出的编辑决策

这些是人的选择，且站得住脚：

1. **十个文明，不是五个。** 非洲（46）、中亚（23）、美洲（50）、大洋洲（15）是在开发过程中被专门扩充的。跳过它们的时间轴不配叫人类时间轴。这是第一版之后打的补丁，不是与生俱来的优点。
2. **每个节点都有正文。** 763 个节点全部有长文——没有占位词条，没有"敬请期待"。这条由测试强制。
3. **没有孤立节点。** 曾找出 76 个孤立节点并补上关联，完整性测试现在禁止回归。一张万物不相连的历史图，教的是错的道理。
4. **2,396 组唯一关联对**，去重、双向，零悬空引用、零自环——全部由测试强制。
5. **576 个节点标记 `important`**，驱动放映机事件流。这是关于"什么配进一部 300 万年概览"的编辑判断，是可以争论的。欢迎开 issue 来争。
6. **没有 emoji，没有游戏化彩带。** 调性是博物馆，不是手游。

## 四、设计灵感

视觉与交互语言借鉴了几个具体传统：

### 博物馆展柜与展签
默认主题是深色木质展柜配暖金细线。节点卡片的形状取自**展签**：方角（2px）、细线、密集小字、左对齐。2px 圆角由 PostCSS 插件在构建期强制，正是为了让这个身份不会悄悄漂移。

### 线装书
竖排阅读模式是从右至左、从上到下，配衬线中文字体——那是古典线装书的版式，不是 CSS 旋转把戏。**竹简**主题把它延伸到墨写竹简的颜色。

### 宣纸与墨
两套主题（**宣纸**、**墨夜**）来自纸墨传统：一套素白供长读，一套 OLED 黑供夜间。**羊皮纸**是西方对应物。五套主题的存在是因为阅读环境本就不同，不是因为主题选择器时髦。

### 卫星考古
底图用 **Esri World Imagery** 而不是政区图。这是刻意的史学选择：对本内容库几乎每一个节点来说，政治边界都是时代错置的。真正约束人类历史的是河流、海岸线、山口与沙漠，卫星影像能显示它们，而不必把现代民族国家图层扣在青铜时代头上。

### 时间轴工具与大战略游戏
泳道视图与历史放映机欠了两笔债：学术界的平行时间轴图表，以及大战略游戏的时代推进界面。放映机那个从公元前 300 万年扫过来的年份游标，毫不掩饰是后者——看着时间移动，是感受尺度的一种真正有效的方式。

## 五、技术灵感与依赖

工程站在开源工作之上。完整许可信息见[第三方素材声明](THIRD-PARTY-NOTICES.zh-CN.md)。

| 组件 | 角色 |
|---|---|
| **React 19** + **Vite 8** | 应用与构建 |
| **TypeScript 5.9** | 内容即代码；schema *就是*编辑契约 |
| **Tailwind CSS 4** + **Radix UI** | 样式基元与无障碍菜单/弹层行为 |
| **Leaflet 1.9** | 地图交互 |
| **ECharts 5.6** | 专题馆图表 |
| **Framer Motion 12** | 转场（刻意排除在放映机事件流之外） |
| **Vitest 5** | 154 个单测 + 17 个构建门禁 |
| **lucide-react** | 图标 |

有两个想法比任何库都更塑造了这个项目，值得点名：

- **内容即代码。** 把 261 万字存成带类型的 TypeScript 而不是数据库，意味着每一处史实修正都是一个可评审的 diff、每一条关联都过类型检查、整座图谱是一个谁都能托管的静态产物。它用编辑便利性换了可审计性。对一个历史项目来说，这个交换是对的。
- **门禁胜过意图。** 本项目声称的每一条性能与完整性属性，都由一个能让构建失败的测试强制。没人执行的首屏预算只是一个愿望。这套纪律来自反复发现"声称修好了的东西其实没修好"。

## 六、哪些不是我们的

- **卫星瓦片** —— Esri。不在本仓库任何许可覆盖范围内。
- **字体** —— 站酷小薇、Noto Sans SC、Noto Serif SC，由 Google Fonts 提供。
- **历史事实** —— 没有人拥有它们。CC BY-SA 覆盖的是**我们的文字**，不是文字所描述的事件。

## 七、怎么纠错

1. 用 **史实纠错** 模板开 issue。
2. 写明节点 id、当前文字、更正后文字，以及**一个来源**。
3. 来源指的是学术著作、一手文献、考古报告或机构出版物——不是另一部百科，也不是另一个 AI。
4. 带来源的更正会被合并；不带来源的会被讨论。

这个项目宁可被纠正，也不愿被辩护。
