## 二、回退机制——没有任何静默失败

系统的设计让"缺译文"这件事**可见且优雅**，绝不出故障：

- **界面文案：** `t(key, fallback)` 在键缺失时返回中文 fallback。你看到的是中文，绝不会是 `common.filter` 这种裸键名。
- **节点元数据：** `EN_NODE_META` **只**收录已译节点。未译节点在 overlay 里直接不存在，运行时用中文标题与摘要。
- **节点正文：** `loadNodeBodyBilingual(nodeId, lang)` 返回带 `isFallback` 标志的 `BilingualBodyResult`。英文不可用时，`DetailPanel` 渲染中文正文**外加一张明确的提示卡："English version not yet available"。**

那张提示卡是刻意的功能。**不要为了让覆盖率好看而删掉它。** 读者有权知道自己读的是回退内容。

**性能说明：** 英文词典是动态 import 的。纯中文会话为 i18n 下载的额外字节是 **0**。

## 三、究竟译了什么

### 3.1 界面词典 —— `src/i18n/en-US.ts`

**58 个分组、539 个叶子键。** 覆盖核心阅读路径：顶栏导航、详情面板、地图视图、时间轴、列表视图、泳道、专题馆、放映机、空状态、主题切换器、侧边栏、底部 Tab、时间滑块、加载屏、分片错误视图、对比面板、文明徽章、错误边界。

### 3.2 组件 —— 137 个中 55 个干净

**82 个 `.tsx` 仍含硬编码中文。** 注意"含中文"不等于"未翻译"——其中有些是注释、传给 `t()` 的 fallback 字面量（这是正确且必需的），或数据。但这个数字是剩余工作量的诚实上界。

### 3.3 节点元数据 —— 133 个

在 `src/data/i18n/en-node-meta.ts`，每条带 `titleEn` 与 `summaryEn`。优先顺序是先 `important: true`，再各时代代表节点。

## 四、当前英文模式下已实测确认的缺陷

这些是**真的在浏览器里把界面切到英文、读 DOM** 找出来的，不是看代码看出来的。都是真实且未修的。

| 缺陷 | 细节 | 严重度 |
|---|---|---|
| **时代名未翻译** | 英文模式下仍渲染 史前时代 / 古代文明 / 古典时代 / 中世纪，**尽管 `ERAS` 里已经有 `nameEn`**（`Prehistoric`、`Ancient Civilizations`…）。数据在那儿，渲染没去消费。 | 高——修起来便宜，可见度高 |
| **分类名未翻译** | 政治 / 军事 / 科技 / 文化 / 神话 / 文物 仍是中文，**尽管 `CATEGORIES` 里已经有 `nameEn`**（`Politics`、`Military`、`Science & Tech`…）。与时代名是同一个接线缺口。 | 高 |
| **`html lang` 不更新** | 切到英文后 `document.documentElement.lang` 仍是 `zh-CN` | 中——读屏与断词会用到它 |
| 零散界面字面量 | 筛选（一处）、播放、时代目录、舒适、紧凑，以及 `共 763 个历史节点`、`7 个时代`、`共 238 个节点` 这类计数串 | 中 |
| 节点标题 | 属预期——只有 133/763 有英文元数据 | 已知缺口，非缺陷 |

时代名与分类名这两项是当前最好的入门贡献：译文在数据里已经有了，要做的是接线，不是翻译。

或直接测：

```bash

python3 - <<'PY'
import re, pathlib
tsx = list(pathlib.Path('src').rglob('*.tsx'))
hard = [f for f in tsx if re.search(r'[\u4e00-\u9fff]', f.read_text(encoding='utf-8'))]
print(f'{len(tsx)-len(hard)} / {len(tsx)} 干净')
PY

# 节点元数据条目数
```

## 六、路线图

按"单位工作量的价值"排序，不按难易。

### 阶段一 —— 把已有的东西接上
*小工作量，大可见改善。*

- [ ] 在所有渲染时代名的视图里消费 `ERAS[].nameEn`
- [ ] 消费 `CATEGORIES[].nameEn` —— 六个分类的英文名在数据里都已存在
- [ ] 语言切换时更新 `document.documentElement.lang`
- [ ] 清扫第四节列出的零散字面量

### 阶段二 —— 做完界面
*中等工作量。*

- [ ] 逐个处理仍含硬编码中文的 82 个组件
- [ ] 每个都在浏览器里于 1280px 与 390px、两种语言下验一遍
- [ ] 目标：英文模式下除内容回退外，零用户可见中文

### 阶段三 —— 元数据做到全覆盖
*还剩 630 个节点。*

建议顺序，优先读者最先撞到的：

1. 全部 576 个 `important` 节点（已完成 133，剩约 443）
2. 其余节点按时代推进，大时代优先：中世纪（246）、古典（173）、大航海与近代（108）
3. 长尾：现代（76）、工业（70）、古代（80）、史前（10）

### 阶段四 —— 正文
*748 个节点，约 260 万字。这是长征。*

现实地说，这是**以年计的贡献者投入**，不是一次冲刺。建议批次：

- 一个 PR 一个分片，由懂该时期的人复核。
- 按读者流量而非年代排序——最常被打开的节点优先。
- **质量优先于速度。** 一个未经复核的机翻分片，比一个诚实的中文回退更糟，因为它看起来权威而实际不是。

本项目不会假装这件事快做完了。它大约**做完了 2%**。

### 阶段五 —— 两种语言之外

overlay 模式可以泛化。见[自行修改教程 5.5](CUSTOMIZATION.zh-CN.md)。维护者没有第三语言的计划；欢迎贡献。

## 七、译法约定

已确立且应遵守：

- **人名地名：** 通行英文译名。Qin Shi Huang、Mesopotamia、Ashurbanipal。不要自创罗马化。
- **年代：** BCE / CE，带千分位，走 `src/i18n/format-year.ts`。不要手写年份格式。
- **忠实：** 翻译不得增加、删除或软化史实主张。中文错了就去提史实纠错——不要在英文里悄悄改掉。
- **语域：** 百科式、博物馆展签调性。与中文一致。
- **不用 emoji。** 全站规则。
